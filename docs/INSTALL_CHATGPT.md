# ChatGPT 技能安装

根据 [OpenAI 官方说明](https://help.openai.com/en/articles/20001066-skills-in-chatgpt)，Skills 面向符合资格的 Business、Enterprise、Healthcare、Edu 用户，受工作区设置及产品可用性限制。可用时，在侧栏 Plugins → Skills → Create → Upload from your computer，上传仅包含 `figurine-maker` 技能目录的 ZIP。上传前确认 ZIP 内 `SKILL.md` 和 `references/`、`templates/` 层级完整。实际入口、上传和触发在本账户均为 UNVERIFIED；没有入口时请联系工作区管理员，或使用本地 Codex 运行。

技能只提供指令和模板，不自动安装运行时、Blender、连接器或授权访问用户电脑。ChatGPT 要执行本地工作流须有相应受支持的执行环境和文件访问；请依项目 Windows 指南单独安装运行时。不要把上传 ZIP 当作成功执行或打印验证。
